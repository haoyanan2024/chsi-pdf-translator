# 学籍报告英文助手：详细操作指南

适用版本：1.2.0。普通用户使用 Windows 安装版即可，无需安装 Python，也无需准备配置文件、照片截图或 API Key。

## 1. 下载并安装

1. 打开项目的 [Releases 页面](https://github.com/haoyanan2024/chsi-pdf-translator/releases/latest)。
2. 在最新版下展开 **Assets**，下载 `CHSI-Translator-Setup-1.2.0.exe`。不要把 `Source code (zip)` 当成安装包。
3. 双击安装包，阅读许可证，选择安装位置，按需勾选桌面快捷方式，完成安装。
4. 从开始菜单打开“学籍报告英文助手”。程序安装到当前用户账户，通常不需要管理员权限。

目标系统为 Windows 10（1809 或更新）/ Windows 11 的 x64 设备。当前版本未提供 macOS 安装包、32 位 Windows 安装包或原生 ARM64 安装包，也未在所有目标系统版本上逐一实测。

安装包目前未签名，Windows 可能显示“未知发布者”。先核对下载来源和发布页的 SHA-256；不要关闭系统防护。设备受组织策略限制时，应由设备管理员处理。

可选校验：在下载目录打开 PowerShell，执行以下命令，将输出的 Hash 与同一版本 `SHA256SUMS.txt` 中对应文件的值比较，大小写不影响结果。

```powershell
Get-FileHash -Algorithm SHA256 .\CHSI-Translator-Setup-1.2.0.exe
```

## 2. 准备正确的中文文件

使用学信网直接下载的中文 **《教育部学籍在线验证报告》PDF**。一般应能在 PDF 阅读器中选中文字。

- 保留原始 PDF；无需裁剪证件照或二维码。
- 不使用手机拍照、扫描件、截图转成的 PDF，也不把多个报告合并后导入。
- 《教育部学历证书电子注册备案表》、学位验证报告等其他文件不属于本版本支持范围。
- 文字能选中是必要的初步检查，不能保证所有历史版式都被完整识别。

## 3. 导入并了解界面

点击 **选择中文 PDF**，选择文件；也可以把文件拖到软件窗口。稍等片刻，软件会提取文字、证件照、二维码、验证码和注意事项，并进行本地翻译。

左侧提供 **中文原件** 和 **英文预览** 两个页签，可以切换对照；顶部的放大、缩小、适合宽度按钮作用于当前预览。页面较长时向下滚动。右侧是逐项校准表：

| 列 | 用途 |
| --- | --- |
| 显示 | 控制这一项是否出现在英文 PDF 中 |
| 字段 | 对应中文字段名称 |
| 中文原文 | 软件识别出的原始内容，供对照 |
| 英文译文（可编辑） | 双击后输入或修正英文，离开单元格完成修改 |
| 状态 | 提示译文来源和是否需要处理 |

顶部摘要会显示主表字段数量、照片和二维码是否提取成功，以及当前所选字段中待翻译、建议核对的数量。若出现识别警告，先与中文预览逐项对照。

## 4. 校准英文内容

1. 双击需要调整的 **英文译文** 单元格。
2. 输入正确译文，按 Enter 或点击其他单元格提交。
3. 软件自动刷新英文预览，状态变为“已校准”。刷新时部分操作会短暂禁用。
4. 译文本来正确时，可选择对应行，点击 **标记选中项已核对**。

重点核对姓名与护照拼写、学校与院系的正式英文名称、专业、日期和学籍状态。姓名的自动拼音不能可靠判断所有多音字；自动翻译也不等于已经人工核实。

| 状态 | 含义与操作 |
| --- | --- |
| 自动翻译 | 已按离线词库或规则翻译，仍建议对照检查 |
| 建议核对 | 有自动结果，但姓名等内容需要人工确认 |
| 待翻译 / 未提取到 | 显示该字段时需要补充或校准，否则不能导出 |
| 已校准 / 已核对 | 已编辑，或已由用户确认 |
| 原文空白 | 原件有空白值，或该常用项未出现在原件中；结合中文列和勾选状态判断 |
| 机器翻译·请核对 | 采用可选网络服务得到的结果，需要复核 |

示例：把姓名译文修正为护照上的拼写后，查看英文预览中的 Name 行；不要为消除状态提示而随意改变原始学籍事实。

## 5. 设置分院、系所及其他字段的显示

### 默认行为

默认按中文原件中已识别的字段及顺序显示，包括原件中的空白行。例如原件中“分院”为空、“系所”为某研究所，英文主表会保留空白的 College 行，并显示 Department / Institute 的译文。

分院、系所、班级、学号直接进入主表。软件没有“附加原文额外字段”的附页开关，每一行都由自己的 **显示** 复选框控制。

### 隐藏或恢复某一项

- 取消一行的勾选：标签与译文一起从 PDF 消失，后续行向上排列，不留下原行的空位。
- 重新勾选：恢复该项并自动重排。原文和已编辑译文仍保留。
- 点击 **恢复原文字段**：重新按中文原件决定显示哪些项，不撤销你已经校准的英文。
- 日期、验证码和注意事项中提供的文字项也可独立选择；这不等于独立控制证件照或二维码图片。

### 原件未出现的常用项

原件未出现的班级、学号等受支持字段默认不勾选。确有需要时，在该行输入英文值并勾选即可；软件不会替你推测这些内容。该版本提供固定的常用字段列表，尚不支持在界面中任意创建自定义字段名或拖动行来改变顺序。

### 字多时的排版

软件保留参考模板的花边、背景、标题与核验区域，根据所选字段和文字长度自动换行、调整行距，并在需要时适度缩小字号。输出保持单页。如果仍放不下，会提示缩短译文或减少所选字段，不静默裁掉文字。修改后检查右侧照片附近和底部核验区域是否清楚。

## 6. 检查照片与二维码

点击 **检查 / 更换照片** 或 **检查 / 更换二维码** 查看提取结果。正常情况下，软件直接使用 PDF 内嵌的原始图片，无需手工操作。

如果提取错误，可以在弹出的窗口中选择正确图片替换。二维码应来自同一份原始报告。请对照原件核实图片、验证码和链接是否对应；导出翻译件不会为原报告重新签发验证码或延长有效期。

## 7. 可选的联网翻译

未收录的学校、专业、分院或系所，可以直接手工输入正式英文名。也可点击 **联网翻译待处理术语**：

1. 阅读软件列出的拟发送术语。
2. 确认后，软件将这些术语发给 MyMemory，尝试取得英文结果。
3. 对照正式名称校准，状态“机器翻译·请核对”仅说明结果来自网络。

默认处理完全离线。可选网络翻译不上传整份 PDF、姓名、照片或验证码；隐藏字段不参加该操作。网络服务不可用或达到配额时，可继续手工校准，不影响本地功能。

## 8. 保存草稿与导出

**保存草稿** 会生成 `.chsi.json` 文件，保留中文原文、英文译文、字段显示选择、照片、二维码和中文预览。下次点击 **打开草稿** 即可继续，不需要重新导入 PDF。草稿不是最终英文 PDF，也不是脱敏文件；取消显示的字段仍保存在草稿中。

打开旧版草稿会保留已有译文，并按原件恢复默认显示选择。旧版附页选项不再影响输出。

导出操作：

1. 处理所有当前勾选的“待翻译 / 未提取到”项。
2. 切换到英文预览，从顶部看到底部，必要时点击 **刷新英文预览**。
3. 点击 **导出英文 PDF**，选择新的文件名和保存位置，例如 `English-reviewed.pdf`。
4. 用 PDF 阅读器再次打开，检查花边、主表、长译文、照片、核验区和注意事项。

中文输入文件不能作为输出目标覆盖。导出 PDF 和保存草稿是两个独立操作，想保留可编辑进度时记得保存草稿。

快捷键：`Ctrl+O` 选择 PDF，`Ctrl+S` 保存草稿，`Ctrl+E` 导出 PDF。

## 9. 更新与卸载

更新前保存草稿并关闭软件。下载新版安装器后运行，安装到原目录；若安装程序提示应用正在运行，先关闭再继续。不要仅从安装目录中拷贝 `CHSITranslator.exe` 给别人，它依赖同目录的运行库；分发应使用完整安装器。

卸载通过 Windows 设置的“应用 / 已安装的应用”找到“学籍报告英文助手”。自行保存到其他目录的 PDF 和草稿应由你管理；建议始终把资料放在个人文档目录，而非软件安装目录。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 下载后没有安装程序 | 到 Releases 的 Assets 下载 `Setup-版本.exe`；源码 ZIP 不含可直接双击的安装器 |
| 提示未识别报告、文本过少或字段缺失 | 确认是正确种类、带文字层的学信网原始 PDF；重新下载原件。扫描件目前没有 OCR 支持 |
| 学校、专业或院系没有英文 | 词库未覆盖时双击英文栏补充，或尝试可选联网翻译 |
| 无法导出 | 查看当前勾选字段的待处理提示；补全译文。确实不需要的项可取消显示 |
| 原件没有班级，界面却列出了班级 | 它是默认未勾选的可选项，不会自动进入 PDF |
| 空白分院行还在 | 默认保留原件空白行；希望隐藏时取消 College 对应行的勾选 |
| 显示“单页放不下” | 精简过长译文，或取消不需要的字段，然后再次预览 |
| 修改后预览暂时不可操作 | 等待后台刷新；如有错误按提示处理后点击刷新预览 |
| 日期与期望不同 | 以中文原件为准；原件没有失效日期时软件不会推算一个日期 |
| 导出的文件被占用 | 在 PDF 阅读器中关闭同名文件，或选择新文件名后重试 |
| 软件启动异常 | 重新下载并校验完整安装包，安装到当前用户可写的目录；记录版本、系统版本和错误信息提交 Issue |

反馈请使用项目 Issues，提供复现步骤和已脱敏的信息。公开 Issue 中不要上传真实报告、照片、二维码、验证码、学号或草稿。

## 输出性质与隐私

本工具生成可人工校准的英文翻译件，不是学信网或教育部官方签发的英文报告。是否接受翻译件应以材料接收方的要求为准。

程序默认离线，不进行遥测，不自动记录含个人信息的应用日志。你主动保存的原件、草稿和英文 PDF 仍包含个人资料，应按原始报告的敏感程度保管。
